# Site Overview

## Interactive Web Desktop Experience

UNHINGED presents a futuristic browser desktop operating system interface:

- **Startup Sequence**: Custom animated splash screen with logo reveal and custom audio.
- **Desktop Environment**: Custom wallpaper, interactive app shortcuts, taskbar, start menu, system tray.
- **Window Management**: Draggable, resizable, focusable, minimizable, and maximizable window components.
- **System Store**: State managed via Zustand (`desktopStore.ts`) tracking open windows, active apps, theme settings, and taskbar state.

## Core Capabilities & Services

1. **Orbit AI Agent**: General team assistant for productivity, scheduling, and task management.
2. **Icebound AI Agent**: Problem-solving agent for technical analysis and code execution.
3. **Knowledge Vault & RAG**: Markdown-backed storage with vector embeddings for semantic document search.
4. **Admin Console & Microservices**: User, group, workspace, plugin, audit logging, and GDPR compliance APIs.
